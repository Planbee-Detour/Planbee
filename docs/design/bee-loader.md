- 작성일: 2026-09-13

## 1. 목적

AI 가 결과를 만드는 동안(추천 조회 등) 보여주는 로딩 표시. 브랜드 가이드가 벌 모티프를 허용한
자리 중 **"AI loading state"** 에 해당한다 (`planbee-design-prompt.md` — "Use small bee or hexagonal
motifs only for … AI loading state"). 일반 목록 로딩(스켈레톤)이나 버튼 안의 작은 스피너를
대체하지 않는다.

**이 컴포넌트는 캐릭터와 움직임만 책임진다.** 안내 문구·배경·레이아웃·오류 전환은 쓰는 화면이
정한다 (추천 화면의 `design.md`).

## 5. 모션

두 모션 모두 **무한 반복**이고, 날갯짓은 공통이다. 수치는 96pt 기준이며 이동 거리는 `size` 에 비례한다.

### 5.1 공통 — 날갯짓

- 날개 묶음을 회전 중심 기준으로 **위로 14° ↔ 아래로 10°** 왕복. 한 번 왕복 **240ms**, ease-in-out.
  - 날개는 몸의 왼쪽에 있으므로 "위로" 는 **시계 방향** 회전이다. 부호 규약이 도구마다 다르니 방향으로 읽는다
    — pen 의 `rotation` 은 반시계가 양수(위로 14° = `-14`), RN `transform: rotate` 는 시계가 양수(위로 14° = `'14deg'`).

### 5.2 `float` — 둥실 (기본값)

- 몸+날개 전체가 **위로 6pt** 떠올랐다가 돌아온다. 한 번 왕복 **1600ms**, ease-in-out.
- 느린 둥실 + 빠른 날갯짓의 대비가 "제자리에서 찾는 중" 을 전한다.

### 5.3 `orbit` — 가로로 긴 타원 궤도

(2026-09-13 사람 요청으로 원형 → 가로 타원. 아래 비율은 요청을 받아 정한 값이며 시뮬레이터에서 보고 조정한다)

- 캐릭터를 **`size` × 0.5** 로 줄이고, 상자 중심을 기준으로 **가로 반지름 `size` × 0.25 ·
  세로 반지름 `size` × 0.10** 의 타원을 그리며 돈다. 시계 방향, 한 바퀴 **3600ms**, 등속(linear).
  - 가로 반지름은 캐릭터가 상자 밖으로 나가지 않는 최대치다 (캐릭터 절반 0.25 + 반지름 0.25 = 0.5).
- **넓게 꼬불꼬불 난다** (2026-09-13 사람 요청 — "너무 정직하게 난다" → "너무 좁게 꼬불거린다").
  타원을 도는 동안 위아래로 **한 바퀴에 3번, 폭 `size` × 0.09** 로 크게 흔들리고, 흔들림에 맞춰
  **±6°** 를 더 기울인다. 세로로 가장 멀리 가도 캐릭터 절반 0.25 + 0.10 + 0.09 = 0.44 라 상자 안이다.
- 캐릭터는 **똑바로 선 채** 이동한다 (진행 방향으로 돌지 않는다 — 뒤집혀 보이지 않게).
  대신 타원의 좌우 끝에서 **±8°** 기울어 방향감을 준다.
- 궤도선은 그리지 않는다.

### 5.4 동작 줄이기

iOS "동작 줄이기" / Android "애니메이션 제거" 가 켜져 있으면 **모든 움직임을 멈추고** 정지한
캐릭터(날개 0°, 이동 0)를 보여준다. `orbit` 도 궤도 없이 가운데에 원래 크기로 선다.
설정이 바뀌면 즉시 따른다.

## 7. 접근성

- 역할은 `progressbar`(진행 정도 없음)다. 캐릭터의 부위는 스크린리더에 노출하지 않는다 — 상자 하나로 읽힌다.
- **나타날 때 소리 내어 알리는 것은 이 컴포넌트가 하지 않는다.** 로딩 화면 진입 안내는 화면이
  `shared/lib/a11y` 로 한다 (M-20) — 같은 화면에 로더가 여러 번 그려질 때 중복 낭독을 막기 위해서다.
- 색만으로 전달하는 정보가 없다.

## 8. 플랫폼

- iOS·Android 동작이 같다. `AccessibilityInfo.isReduceMotionEnabled` 와 네이티브 드라이버
  애니메이션이 두 플랫폼에서 같은 API 이므로 분기가 필요 없다 (M-20 — 분기가 필요한 곳만 분기).

## 9. 이 컴포넌트가 하지 않는 것

- 안내 문구, 경과 시간에 따른 문구 변경, 취소 버튼, 타임아웃·오류 화면 — 쓰는 화면의 명세가 정한다.
- 배경 면·카드 — 상자는 투명하다.
- 진행률 표시.
