# UI/UX 명세: 주변 장소 탐색 (`nearby-places`)

## 1. 내비게이션

- 홈 "지금 주변에는"의 "더보기"를 누르면 `NearbyPlacesScreen`을 push한다.
- 상단 "뒤로"는 홈으로 pop한다. 하단 탭 바는 표시하지 않는다.
- 기본 모드는 "목록"이다. 상단 세그먼트 "목록"/"지도"로 같은 결과를 전환한다.
- 목록 카드와 지도 하단 카드는 `PlaceDetailScreen(placeId)`를 push한다.

## 2. 공통 구조와 문구

- 제목: "주변 장소"
- 보조 문구: "현재 위치에서 가까운 장소를 모았어요."
- 빠른 필터: "거리순", "운영 중", "실내", "카페"
- API 준비 전에는 필터를 시각적 컨트롤로만 표시한다.

## 3. 상태

### 정상 — 목록

- 세로 `Card/PlaceRow` 목록을 기본 표시한다.
- 각 행은 이미지, 카테고리, 운영 상태, 이름, 거리, 태그를 표시한다.

### 정상 — 지도

- 목 지도 위에 장소별 마커를 표시한다.
- 선택 마커는 Honey 색상과 큰 크기로 구분한다.
- 선택 장소의 `Card/Place`를 하단에 표시한다. 마커나 카드 탭으로 상세에 진입한다.

### 로딩

- 헤더는 즉시 표시하고 목록 행 세 개를 스켈레톤으로 표시한다.
- 스크린리더 문구: "주변 장소를 불러오는 중".

### 비어있음

- 제목: "주변에서 추천할 장소를 찾지 못했어요"
- 본문: "지역을 바꾸거나 잠시 후 다시 확인해 주세요."
- 버튼: "이전 화면으로"

### 오류

- 제목: "주변 장소를 불러오지 못했어요"
- 본문: "연결을 확인하고 다시 시도해 주세요."
- 버튼: "다시 시도", "이전 화면으로"

## 4. 접근성

- 모든 터치 영역은 최소 44×44pt다.
- 마커 레이블은 "{장소명} 마커"다.
- 선택 여부는 색뿐 아니라 하단 장소 카드로도 표현한다.
