# PRD: 주변 장소 탐색

- 기능 슬러그: `nearby-places`
- 작성일: 2026-08-29

## 배경 / 문제

홈의 제한된 장소 카드만으로는 주변 선택지를 충분히 비교하기 어렵고, 지도 마커만으로는 장소를 식별하기 어렵다.

## 목표

- 홈의 "더보기"에서 주변 장소 목록으로 진입한다.
- 목록과 지도를 전환하고, 지도 마커 선택 시 장소 카드를 함께 표시한다.
- 어느 카드에서든 기존 장소 상세 화면으로 진입한다.

## Out of scope

- 실제 지도 SDK와 지도 타일, 위치 권한 추가, 서버 호출
- 지도 이동에 따른 재검색, 클러스터링, 필터 API

## 유저 스토리와 인수조건

### US-NP-1. 여행자로서 주변 장소를 비교하고 싶다

| ID | 인수조건 |
|---|---|
| AC-NP-1 | 홈의 "더보기"를 누르면 주변 장소 화면이 push되고 목록이 기본 표시된다. |
| AC-NP-2 | "목록"과 "지도"를 누르면 같은 장소 집합의 표현이 전환된다. |
| AC-NP-3 | 지도 마커를 누르면 해당 장소의 하단 카드가 선택 상태로 표시된다. |
| AC-NP-4 | 목록 또는 지도 카드를 누르면 해당 `place_id` 상세 화면이 push된다. |
| AC-NP-5 | 로딩·정상·비어있음·오류 상태가 존재한다. |
| AC-NP-6 | 오류 상태에서 다시 시도하거나 이전 화면으로 돌아갈 수 있다. |

## 제약

- API 준비 전에는 미래 계약과 같은 로컬 JSON fixture만 사용한다.
- 지도는 실제 SDK 없이 공간 배치와 선택 동작만 검증하는 목 UI다.

## 열린 질문

- 지도 SDK, 비용, 위치 권한 문구와 배포 신고는 도입 전에 사람이 결정한다.
- 클러스터링과 "이 지역에서 다시 찾기"는 실제 지도 도입 시 결정한다.
