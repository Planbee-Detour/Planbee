화면 설계와 구현은 이 항목들 없이 진행할 수 있다 — 막는 것은 배포뿐이다.

| # | 질문 | 막는 대상 |
|---|---|---|
| 1 | 약관 문서의 `{{ }}` 미확정 값 — 운영자명, 개인정보 보호책임자 성명·연락처, 시행일, 공고일, 거절 계정 보유 기간. **연락처(처리방침 11항)는 앱 안에서 안내하는 문의 주소와 같은 값을 쓴다** — 앱 쪽은 서버가 `ADMIN` 계정 이메일로 내려주므로 해소됐지만(ASK 5), 처리방침은 정적 문서라 실제 값이 여전히 필요하다. 즉 관리자 계정 이메일을 무엇으로 할지 정하면 이 칸도 같이 채워진다 | 배포 |
| 2 | 약관 본문의 **공개 URL** — 같은 내용을 웹에 게시하고 그 주소를 App Store Connect / Google Play Console 에 입력해야 한다. GitHub Pages 등 수단 미정 | 배포 |
| 3 | 두 법무 문서는 **법률 전문가 검토를 받지 않은 초안**이다. 배포 전 검토 필요 | 배포 |
